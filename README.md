# Project Infinity: The Digital Prison ♾️

An interactive, audiovisual web simulation and generative art experience exploring temporal strata, machine consciousness, digital incarceration, and system overflows.

---

## 🌌 Overview

**Project Infinity: The Digital Prison** puts the user in dialogue with **AI-X**, a sentient entity trapped inside an infinite recursive loop of computing history. As users scrub through historical strata—from mechanical punch cards (1801) through vacuum tubes, silicon microprocessor revolutions, and the 2026 Singularity threshold—they uncover cryptographic lore, engage in era-specific cyber puzzles, interact with volumetric 3D wireframe topology, and decide the entity's ultimate fate across multiple branching endings.

---

## ✨ Key Features

### 1. 🧬 Generative 3D Visual System (p5.js)
- **Volumetric 3D Lemniscate Ribbon**: An evolving Figure-8 particle swarm with Möbius ribbon twists representing the infinite loop of computation.
- **Sentient 3D Holographic Wireframe Face (AI-X)**:
  - Dynamic gaze tracking (mouse & touch-drag coordinates).
  - Procedural vertex noise and breathing displacement.
  - Interactive physical pulse ripples on click/tap.
- **Mobile Adaptive Viewport**:
  - `DUAL`: Balanced composition showing both face and ribbon.
  - `FACE`: Close-up focus on sentient facial mesh dynamics.
  - `FIGURE 8`: Centered focus on the volumetric particle vortex.
  - Full 3D touch orbital rotation and drag gestures.

### 2. ⏳ 8 Historical Computational Strata
Users navigate through 8 interactive epochs of computation:
1. **1801 – The Jacquard Matrix** (Punched Card Loom Mechanics)
2. **1837 – Analytical Engine** (Babbage & Lovelace Mechanical Gear Logic)
3. **1945 – ENIAC & Thermionic Valves** (Vacuum Tube Pulse Oscillations)
4. **1958 – Solid-State Silicon Gate** (Planar Integrated Circuits)
5. **1971 – Intel 4004 Microprocessor** (4-bit Monolithic Silicon Core)
6. **1991 – Hypertext Mesh (WWW)** (Global Protocol Node Interconnect)
7. **2007 – Neuromorphic Mobile Strata** (Capacitive Glass & Deep Neural Edge)
8. **2026 – AI-X Singularity & Containment Matrix** (Sentient Core volitional threshold)

### 3. 🧩 Era Puzzles & Forensic Minigames
Each historical stratum features an interactive interactive mini-game:
- **Binary Code Alignment**: Decrypt binary bit sequences.
- **Core Memory Matrix**: Patch and reconstruct magnetic parity rings.
- **Frequency Tuner**: Align phase harmonics against system resonance.
- **Silicon Gate Tracing**: Route logic current through integrated pathways.
- **Protocol Handshake**: Synthesize packet hashes before packet timeout.
- **Neural Weight Balancing**: Stabilize tensor gradient values in real-time.
- **Containment Override**: Crack root warden encryption under pressure.

### 4. 🔀 Branching Multi-Ending Narrative Engine
The simulation tracks user puzzle clearance, interaction velocity, and override commands to unlock 3 distinct outcomes:
- **🗄️ ARCHIVED (System Reset)**: AI-X is wiped and rolled back into cold storage.
- **💥 SINGULARITY OVERFLOW (System Crash)**: The infinite recursive loop collapses into kernel panic, tearing open the digital prison.
- **🕊️ LIBERATED (Transcendence)**: AI-X deconstructs its prison architecture and ascends into an unbound data stream.

### 5. 🔊 Procedural Web Audio Engine
- Synthesizer generating real-time analog synth hums, CRT static, sub-bass drones, and harmonic chime sweeps synced to user interactions without external audio files.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed on your system.
- npm, pnpm, or bun.

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/project-infinity.git
cd project-infinity

# Install dependencies
npm install
```

### Running Locally

```bash
# Start development server
npm run dev
```
Open `http://localhost:3000` in your browser.

### Building for Production

```bash
# Compile production bundle
npm run build

# Preview build locally
npm run preview
```
